# AI 翻译助手（AI Translator）

一款基于主流 AI 大模型的浏览器翻译插件，提供 **划词翻译、整页翻译、输入框翻译** 三种方式，支持 **50+ 种目标语言** 与 **多家 AI 服务商**，也可完全离线使用本地模型。

- 基于 Manifest V3，支持 **Microsoft Edge**（推荐）与 **Google Chrome**
- 多服务商：DeepSeek、OpenAI (ChatGPT)、通义千问、Kimi、智谱 GLM、Google Gemini、本地 Ollama

## ✨ 功能特性

| 功能 | 说明 |
| --- | --- |
| 划词翻译 | 选中网页文字立即弹出翻译气泡，可一键复制译文 |
| 整页翻译 | 一键翻译整个网页，过程中可随时暂停 / 继续 / 取消，取消自动还原原文 |
| 输入框翻译 | 在网页输入框中输入内容，自动弹出译文预览，可一键替换或复制 |
| 下载译文 | 整页翻译完成后可下载纯文本（.txt）或完整快照（.mhtml，保留原样式和图片） |
| 多服务商 | 内置 7 家主流 AI 服务商，各自独立保存 API Key 与模型，支持自定义模型名 |
| 多语言 | 50+ 目标语言，源语言自动识别 |
| 设置自动保存 | 切换服务商 / 模型 / 语言即时生效，无需手动保存 |
| 本地离线 | 连接本机 Ollama，翻译完全离线，数据不出本机 |
| 右键菜单 | 翻译选中文本 / 翻译整页 / 还原整页 |

## 📦 安装

### 方式一：从商店安装（推荐）

Microsoft Edge Add-ons 搜索「AI 翻译助手」安装（商店链接待扩展上架后补充）。

### 方式二：开发者模式加载（本地调试）

1. 克隆本仓库：
   ```bash
   git clone <仓库地址>
   ```
2. 打开 Edge，地址栏输入 `edge://extensions` 回车
3. 打开左下角「开发人员模式」
4. 点击「加载解压缩的扩展」，选择本仓库目录
5. 点击浏览器工具栏的插件图标，选择 AI 服务商并填入 API Key（自动保存），点「测试连接」验证

## 🚀 使用说明

- **划词翻译**：选中网页文字，松手后出现翻译气泡；点「复制」复制译文
- **整页翻译**：右键页面 →「AI 翻译：翻译整页」；翻译中可暂停 / 继续 / 取消；完成后右下角出现「下载文本 / 下载快照 / 还原原文」按钮
- **输入框翻译**：聚焦输入框并输入内容，停止输入约 1.2 秒后弹出译文预览；点「替换」用译文替换原文（可再点输入框右下角按钮还原）
- **快速翻译**：点击插件图标，在弹窗底部输入任意文本即可翻译

## 🛠 支持的服务商

| 服务商 | 默认模型 | 说明 |
| --- | --- | --- |
| DeepSeek | deepseek-chat | 国内直连，性价比高 |
| OpenAI (ChatGPT) | gpt-4o-mini | 国内访问需代理 |
| 通义千问（阿里） | qwen-plus | 国内直连 |
| Kimi（月之暗面） | moonshot-v1-8k | 国内直连 |
| 智谱 GLM | glm-4-flash | 国内直连，有免费额度 |
| Google Gemini | gemini-2.5-flash | 国内访问需代理，有免费额度 |
| 本地 Ollama | qwen3:8b | 免费离线，需本机安装 Ollama |

所有服务商均走 OpenAI 兼容接口；除预设模型外，还可用「自定义模型」填写任意模型名。

## 🔒 隐私说明

- API Key 仅保存在浏览器本地（`chrome.storage.local`），不会上传到任何其他服务器
- 仅在您主动发起翻译时，将待翻译文本发送给您所选的服务商
- 使用本地 Ollama 时，数据完全不出本机
- 不使用远程代码，不含广告
- 完整隐私政策见 [privacy-policy.html](publish/privacy-policy.html)

## 📂 项目结构

```
├── manifest.json      # 扩展清单（Manifest V3）
├── background.js      # 后台 Service Worker：调用各服务商 API、右键菜单
├── content.js         # 内容脚本：划词 / 整页 / 输入框翻译逻辑
├── content.css        # 页面内 UI 样式
├── popup.html         # 插件弹窗界面
├── popup.js           # 弹窗逻辑（自动保存、测试连接、快速翻译）
├── icons/             # 扩展图标
└── publish/           # 商店发布相关文件（打包、上架文案、隐私政策）
```

## ❓ 常见问题

| 问题 | 处理 |
| --- | --- |
| 测试连接一直转圈 / 翻译长时间无响应 | 本地模型空闲后会被 Ollama 卸载，重新加载需 30~60 秒；执行 `setx OLLAMA_KEEP_ALIVE "-1"` 并重启 Ollama 让模型常驻 |
| 本地模型翻译很慢 | CPU 上运行 8B 模型较慢属正常；可换 qwen3:4b 提速，或改用云端服务商 |
| 403 错误 | 浏览器扩展访问本地 Ollama 需放行来源：`setx OLLAMA_ORIGINS "*"` 后重启 Ollama |
| 下载快照里图片缺失 | 页面懒加载 / JS 动态注入的图片可能无法捕获，属浏览器快照机制限制 |
